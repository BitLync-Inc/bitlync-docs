Quickstart

Connector setup

What the MSP pastes into Connect for each tool, and which region or URL to use.

The fields the MSP fills in on the Connect step for each tool, with the help text Connect shows. Secret fields are never pre-filled or shown again.

ConnectWise

PSA

Fields

FieldHelp
ConnectWise company IDPlaceholder summitpeak.
API member public key—
API member private keyShown once in ConnectWise — copy it before leaving that page.
Integration clientIdBitlync fills this. Leave it as shown — you do not register a client ID.
API base URLPlaceholder https://na.myconnectwise.net/v4_6_release/apis/3.0. The exact version segment varies per instance.

Region and URL

Set by the API base URL. Core's example is the na.myconnectwise.net host.

Notes

  • Gap: core lists no other ConnectWise region hosts, so none are listed here.

HaloPSA

PSA

Fields

FieldHelp
Client ID—
Client secretShown once when you create the API application — copy it before leaving that page.
Auth server URLPlaceholder https://your-instance.halopsa.com/auth. Full URL from Configuration → Integrations → HaloPSA API → API Details.
Resource server URLPlaceholder https://your-instance.halopsa.com/api. Full URL ending in /api from API Details.
Tenant ID (optional)Leave blank unless Halo shows a tenant id on API Details (multi-tenant hosted only).

Region and URL

Set by the two server URLs from API Details. Halo has no region picker.

Notes

  • Ticket writes don't send Halo notification emails, and notes are internal by default.

SuperOps

PSA & RMM

Fields

FieldHelp
API tokenGenerate this token from a technician user with a limited role (tickets, clients, contracts, custom fields), not an admin: a SuperOps token inherits the role of the user who creates it. Log in as that technician, then Settings → My Profile → API token → Generate. Copy it before leaving that page.
SubdomainPlaceholder yourcompany. Settings → MSP Information. Just the subdomain, not the full URL.
RegionPick US or EU — the data center your SuperOps account uses.

Region and URL

US: https://api.superops.ai/msp. EU: https://euapi.superops.ai/msp. A blank region is treated as US. A wrong subdomain or region returns HTTP 400.

Notes

  • Full detail: SuperOps.

Datto RMM

RMM

Fields

FieldHelp
API keySetup → Users → the integration user. Copy the API key.
API secretShown once on that same user when you generate the API secret.
API URLPlaceholder https://pinotage-api.centrastage.net. Use this account's platform API host (…-api.centrastage.net), not the web console.

Region and URL

One host per platform: https://pinotage-api.centrastage.net, https://merlot-api.centrastage.net, https://syrah-api.centrastage.net, https://vidal-api.centrastage.net, https://zinfandel-api.centrastage.net, https://concord-api.centrastage.net.

Notes

  • None beyond the field help.

IT Glue

Documentation

Fields

FieldHelp
