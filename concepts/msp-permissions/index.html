Concepts

MSP permissions

A missing grant is HTTP 403, code grant_missing. A parked vendor permission is HTTP 409, code scope_parked. An unsupported capability is HTTP 501, code unsupported_capability.

ConnectWise and Halo connect are numbered click paths. Halo takes a client ID, a client secret, and the two server URLs. A missing permission is named in English. Company create runs when the MSP turns on psa.company.create. Match runs first. Two matches return company_match_ambiguous. Agreement-line writes run when the MSP turns on that grant, on an existing agreement.

ISV experience config

GET|PUT /isv/experience-config sets category config for PSA, RMM, Docs, CS, and Commerce, plus recommended grants and branding. Vendors inherit the category template. Access is List, Read, and Write, and those stack. Never is its own setting. The MSP can tighten the starting verbs. Recommended grants drive Connect rows. Sandbox Experience Preview (POST /connect/sessions/preview and console #/experience) walks Connect: keys, grants, boards, map, done. Getting Started on Setup is Suggest, Save, Preview, then Use MCP or Use API. After Save, copy-paste prompts follow the saved profile. Partner credentials and Production MSP Connect keys are separate. Connections lists each MSP and vendor, last sync, and sync detail. Issues gives a support blurb and a redacted request debug.

Mechanism

The MSP pastes keys in the guided flow. The probe names the permission to fix. The ISV does not paste MSP creds.
