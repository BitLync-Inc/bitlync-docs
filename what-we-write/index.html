What we write

What we write.

Billing line items on an existing agreement.

POST a billing line on an existing agreement. Parameters: the agreement, the verb (new, modify, replace, or end), and dry_run (default true). ConnectWise and Halo. dry_run true returns the payload. dry_run false commits that payload.

You need an active agreement so we can write the line.

Tickets are two-way when the MSP grants it. You can create, update, and close. You can subscribe to events when the MSP changes the ticket in their PSA.

Time on a linked ticket needs a required member. List with GET /tenants/{tenant_id}/members. Halo and ConnectWise return that list when the member permission is on. Autotask members are Resources. A missing ConnectWise members permission returns 502 upstream_auth_failure. The time picker uses the listed id.

When a device is created or updated, you can list those events or get a signed webhook. After a tenant sync, GET /tenants/{id}/connections/events?kind=device.updated (also created). Optional signed webhook. Grant is the connection (rmm.device.events). Missing is grant_missing.

When a company is created or updated, you can list those events or get a signed webhook. After a tenant sync, GET /tenants/{id}/connections/events?kind=company.updated (also created). Optional signed webhook. Grant is the connection (psa.company.events). Missing is grant_missing.

Reads include vendor: { connector, native_id, native }. native is the same payload as .raw. Ticket writes accept optional vendor_native on POST /tickets and POST /tickets/write. POST /companies/write writes a Halo company custom field (customfields or cf*) on an allowlisted sandbox host when psa.company.update is on. A missing grant is grant_missing.

Company create runs when the MSP turns on psa.company.create. Match runs first. Two matches return company_match_ambiguous.

Device write runs when the MSP turns on that grant. Exact-name Match fills Match when one PSA company name hits one ISV customer. Ambiguous names stay Needs match. Each row is Match, company import from PSA, or Skip. Bulk unmatched import takes a dry_run preview. Company import creates the customer in the ISV. Contacts are list and match. Ticket create and update take board, status, and priority ids from the ConnectWise and Halo lists. An unknown id returns 422. Autotask lists queues, statuses, and priorities. A missing grant is grant_missing.

A write that does not apply returns a stable code, one sentence, and doc_url.

agreement_header_not_supported — the call asked to create an agreement.

agreement_requires_existing — missing or unknown agreement.

ConnectWise and Halo write on an existing project.

project_requires_existing — missing or unknown project.

project_header_not_supported — the call asked to create a project.

project_not_writable — this project will not take the write.

project_company_cannot_update — the project’s company cannot be updated.

Pax8 matches companies it already has, then creates the rest. Company create runs when the MSP turns on the grant. Match runs first. Two matches return company_match_ambiguous.

psa_company_create_refused — the grant is on and this create did not run. A missing grant is grant_missing.

psa_company_update_refused — the grant is on and this company update did not run.

company_match_ambiguous — more than one match.

distributor_required — no connected distributor for this write.
