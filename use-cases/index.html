Use cases

The paths.

The jobs. Alert to ticket through check an asset.

1. Alert to ticket

A finding becomes a ticket we created. We keep the link. You can update, append a note, or close with evidence on that ticket.

2. Import, map, and create customers

Sure match auto-maps. A leftover is an ask. * We do not create the customer in a PSA. The partner creates them there, where the contract lives. Until they are in the PSA, they are not a customer.

3. Time on the ticket

Hours on a ticket Bitlync already linked. Hours, stated billable, optional member.

4. Billing reconciliation

Read agreements and lines. Write lines on an existing agreement.

5. Create action items

Create the follow-up the MSP already tracks.

6. Create initiatives

Create the workstream those items sit on.

7. Add to an existing project

Add notes or items on a project that already exists.

8. Create an order

Place a third-party licensing order.

9. Write a document

Write into the MSP's documentation tool.

10. Read devices

Pull the device roster.

11. Software inventory

Pull installed software.

12. Check an asset

Pull the documented asset.
